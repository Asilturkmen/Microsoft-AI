# Computer Networking

Computer networks exchange data by following layered protocols. IP handles addressing and routing between networks, while transport protocols provide communication between application endpoints identified by port numbers.

## TCP and UDP

TCP establishes a connection and provides ordered, reliable byte delivery using acknowledgements and retransmission. UDP sends independent datagrams without delivery or ordering guarantees, which lowers overhead for applications that can tolerate loss or manage reliability themselves.

## DNS and HTTP

The Domain Name System translates human-readable host names into IP addresses. HTTP is an application protocol for requesting and transferring resources; HTTPS protects HTTP traffic with TLS encryption, server authentication, and integrity checks.
