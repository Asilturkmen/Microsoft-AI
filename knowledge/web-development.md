# Web Development

A web application usually has a client that runs in a browser and a server that processes requests. HTML describes document structure, CSS controls presentation, and JavaScript adds behavior. Servers expose resources through URLs and return HTTP responses.

## APIs and status codes

A web API defines how programs exchange requests and responses, often using JSON. HTTP methods communicate intent: GET retrieves, POST creates or triggers processing, PUT replaces, PATCH partially updates, and DELETE removes. Status codes such as 200, 404, and 500 summarize the result.

## Accessibility and security

Semantic HTML, keyboard navigation, readable contrast, and text alternatives make interfaces more accessible. Servers must validate untrusted input, enforce authorization, escape output where needed, and use HTTPS to protect data in transit.
